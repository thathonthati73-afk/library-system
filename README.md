# Community Library Management System

BIWA2110 Individual Assignment 2 - built with React, React Router and local storage.

## Run it
```
npm install
npm run dev
```

## Login
First time use: membership ID `ADMIN01` (name `Admin`). Admins can add more users.

## Pages
- Dashboard: stock table, low stock (less than 2) is highlighted
- Books: add, update, delete books
- Transactions: add stock, borrow (deduct stock), history log
- Users: add, update, delete users (admin only)
